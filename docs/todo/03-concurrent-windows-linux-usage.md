# 03 — Concurrent Windows/Linux Usage Design

## Overview

After installation, the same project must be usable from both Windows and Linux/WSL without reinstalling the hook. The hook must not contain environment-specific absolute paths.

## Requirements

### Dual-Environment Execution

| Commit From | Python Used | Hook Entry Point |
|-------------|-------------|------------------|
| Windows Git | Windows Python (active in PATH) | `python <tool_root>/src/precommit_wrapper.py` |
| Linux/WSL Git | Linux/WSL Python (active in PATH) | `python <tool_root>/src/precommit_wrapper.py` |

### No Cross-Invocation

- **Windows never invokes WSL** — no `wsl.exe`, `bash.exe`, `wslpath`, etc.
- **Linux/WSL never depends on Windows** — no `.exe`, `.bat`, `.ps1`, `cmd.exe`, `powershell.exe`

### No Environment-Specific Paths in Hook

The installed hook must **not** contain:
- Absolute paths to Python (`/usr/bin/python3`, `C:\Python312\python.exe`)
- Absolute paths to the repo (`/home/user/project`, `C:\project`)
- Absolute paths to the tool (`/home/user/project/br_pre_commit`, `C:\project\br_pre_commit`)
- Conda/virtualenv activation commands

### Dynamic Path Resolution at Runtime

The hook (or its Python entry point) must resolve at execution time:

```python
# In precommit_wrapper.py
def resolve_paths() -> tuple[Path, Path]:
    # 1. Git repo root (works from any subdirectory)
    repo_root = Path(subprocess.check_output(
        ["git", "rev-parse", "--show-toplevel"],
        text=True, stderr=subprocess.DEVNULL
    ).strip())

    # 2. Tool root — resolve relative to this script or via submodule
    # Option A: relative to this file (if installed as package)
    tool_root = Path(__file__).parent.parent  # src/.. → repo root

    # Option B: via git submodule (if not installed as package)
    # git submodule status br_pre_commit

    return repo_root, tool_root
```

### Fail-Closed Policy for Mixed Environments

If a hook installed for one environment is executed from another:

```
ERROR: This hook was installed for Linux/WSL execution.
       You are running from Windows Git.

       To fix, reinstall from Windows:
         python install/install.py

       Or commit from WSL instead.
```

This is a **clear error**, not a silent fallback.

### No Persisted Environment State

The hook file itself must not record:
- Which Python was used at install time
- Which OS installed it
- Conda environment names
- Virtualenv paths

The only persistent state is the hook file content, which is **platform-agnostic**.

## Design: Platform-Agnostic Hook

### Hook Template (Generated by Installer)

**POSIX (Linux/WSL):**
```bash
#!/usr/bin/env sh
# br_pre_commit hook — generated by installer
# mode: dual
# tool_root: resolved at runtime
exec python <tool_root>/src/precommit_wrapper.py "$@"
```

**Windows (PowerShell):**
```powershell
#!/usr/bin/env pwsh
# br_pre_commit hook — generated by installer
# mode: dual
# tool_root: resolved at runtime
python <tool_root>/src/precommit_wrapper.py $args
```

### Runtime Dispatch in `precommit_wrapper.py`

```python
def main():
    # 1. Detect execution environment
    is_windows = platform.system() == "Windows"

    # 2. Resolve paths dynamically
    repo_root, tool_root = resolve_paths()

    # 3. Validate Python environment
    validate_python_environment()

    # 4. Check dependencies
    check_dependencies(tool_root / "requirements.txt")

    # 5. Execute the actual pre-commit logic
    run_pre_commit(repo_root, tool_root)
```

### Environment Detection

```python
def detect_execution_environment() -> str:
    """Return 'windows', 'linux', or 'wsl'."""
    system = platform.system()
    if system == "Windows":
        return "windows"
    # Linux or WSL — treat identically per 01-system-neutral
    return "linux"
```

## Switching Between Environments

| Scenario | Expected Behavior |
|----------|-------------------|
| Install from WSL, commit from Windows | Hook detects mismatch → clear error with reinstall instruction |
| Install from Windows, commit from WSL | Hook detects mismatch → clear error with reinstall instruction |
| Install from Linux, commit from WSL | Works (same POSIX environment) |
| Reinstall from new environment | Updates hook, preserves any user additions |

## Verification Checklist

- [ ] Hook contains no absolute paths
- [ ] Hook runs on Windows Git with Windows Python
- [ ] Hook runs on WSL Git with WSL Python
- [ ] Hook runs on Linux Git with Linux Python
- [ ] Mixed-environment commit → clear error with actionable fix
- [ ] Reinstall from different environment → works
- [ ] No `wsl.exe` invoked from Windows
- [ ] No Windows executables invoked from Linux/WSL
- [ ] `python -m pip` used for dependency checks (not bare `pip`)
